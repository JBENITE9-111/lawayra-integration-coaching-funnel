# Deployment Guide

## Live Files

The live funnel is now at the repository root.

Required files for deployment:

- `index.html`
- `assets/images/`

## Option 1: Upload To A Funnel Server

Upload the repository root or only the live files listed above.

## Option 2: GitHub Pages

1. Create or open the GitHub repository.
2. Push this folder to the `main` branch.
3. In GitHub, go to `Settings` -> `Pages`.
4. Choose `Deploy from a branch`.
5. Select `main` and `/root`.
6. Save and wait for deployment.

## Before Launch

- Replace the consultation CTA URL with the final calendar or funnel URL.
- Confirm the legal/disclaimer language.
- Confirm all coach bios and photo usage permissions.
- Test on mobile, tablet, and desktop.
