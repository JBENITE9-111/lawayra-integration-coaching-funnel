# Source Intake Checklist

Use this when you upload the final customer/coaching materials.

## Must Have

- Offer name
- Coach/company name
- Coach 1 name, role, credentials, approved bio, photo, and calendar URL
- Coach 2 name, role, credentials, approved bio, photo, and calendar URL
- Coach 3 name, role, credentials, approved bio, photo, and calendar URL
- Logo
- Primary CTA URL: calendar or checkout
- Contact fallback
- Offer format
- Price or pricing strategy
- Duration/cadence
- Audience
- Main pain
- Main outcome
- Coaching method/framework
- What is included
- FAQ answers

## Three-Coach Asset Requirements

- Three final portrait photos, ideally similar crop/orientation.
- Image permission/usage approval for each photo.
- Short alt text for each coach photo.
- One calendar link per coach, or one confirmed shared booking calendar.
- CTA wording for each coach.
- Optional: coach intro videos, testimonials per coach, certifications, LinkedIn/website links.

## Strongly Recommended

- 5-20 writing samples for voice
- Testimonials
- Case studies
- Screenshots/reviews
- Existing website copy
- Social posts
- Sales call notes
- Program curriculum
- Brand guide
- Brand colors/fonts
- Legal/disclaimer requirements

## Optional

- Competitor examples
- Old landing pages
- Email sequence
- Lead magnet
- Analytics/tracking requirements
- CRM integration notes
- Thank-you page copy

## Extraction Output To Produce

After receiving source material, extract:
- Voice profile
- Audience profile
- Pain-point map
- Outcome map
- Offer mechanism
- Proof inventory
- CTA path
- Objection/FAQ map
- SEO metadata draft
- Design direction
- Coach comparison map
- Missing-input list before build
