# Landing Page Deploy Folder

This folder is the deployable static funnel page. It can be uploaded directly to a server, GitHub Pages, Netlify, Vercel static hosting, or a funnel hosting environment.

## Files

- `index.html` - complete landing page with inline CSS.
- `assets/images/` - images required by the live page.

## Current CTA

The CTA says: `Book your free 30 min consultation`.

Before launch, replace `https://ayahuascaincolombia.com` in `index.html` with the final calendar, consultation, or funnel URL.
